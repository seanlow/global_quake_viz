US Geological Survey Visualization

3D Global Earthquake Map

A lightweight interactive 3D view of recent earthquakes, streaming via USGS data.

Run this page through HTTP/HTTPS. Opening index.html directly as a file:// URL prevents the browser from fetching the USGS feed. Use GitHub Pages, VS Code Live Server, or Python's built-in server: python -m http.server 8080, then open http://localhost:8080.
